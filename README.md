# Cadenya Go SDK

The official Go client for the Cadenya API. Generated by redwood.

## Install

```sh
go get go.cadenya.com/cadenya-go
```

## Getting started

```go
import (
	"context"
	"log"

	cadenya "go.cadenya.com/cadenya-go"
)

func main() {
	// Reads CADENYA_API_KEY (and CADENYA_WORKSPACE_ID) from the environment
	// when the options are omitted. Explicitly supplied blank values are
	// errors and never fall back to the environment.
	client, err := cadenya.NewClient()
	if err != nil {
		log.Fatal(err)
	}

	result, err := client.Accounts().Retrieve(context.Background())
	if err != nil {
		log.Fatal(err)
	}
	_ = result
}
```

## Errors

Non-2xx responses return `*APIError` (google.rpc Status: `StatusCode`,
`Code`, `Message`, `Details`), compatible with `errors.As`. Requests that
never reached the server return connection errors.

## Retries

Automatic retries apply only to idempotent methods (GET/HEAD/PUT/DELETE)
and default to 0. Enable with `WithMaxRetries(n)`; opt a single mutation in
with `WithRequestRetries(n)`. `Retry-After` (seconds or HTTP-date) is
honored. Ordinary calls get a 60s context deadline when the caller sets
none; streaming responses never do.


## Pagination

```go
page, err := client.APIKeys().List(ctx, nil)
items, err := page.All(ctx) // fetches every page
// or step manually: page.HasNextPage(), page.GetNextPage(ctx)
```

## Streaming (SSE)

Every successfully constructed stream must be consumed and closed —
`defer` captures the receiver at statement time, so a REPLAY stream needs
its own name, error check, and Close:

```go
stream, err := client.Objectives().StreamEvents(ctx, objectiveID, params)
if err != nil { return err }
defer stream.Close()
for stream.Next() {
	event := stream.Current()
	_ = event
}
if err := stream.Err(); err != nil { return err }

// Resume after a disconnect: pass the last checkpoint back — as a NEW,
// separately closed stream (reassigning the first variable would leak the
// replay: the earlier defer still points at the old stream).
resumed, err := client.Objectives().StreamEvents(ctx, objectiveID, params, cadenya.WithLastEventID(stream.LastEventID()))
if err != nil { return err }
defer resumed.Close()
for resumed.Next() {
	_ = resumed.Current()
}
if err := resumed.Err(); err != nil { return err }
```

