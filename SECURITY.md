# Security Policy

## Reporting Security Issues

We take security seriously and encourage you to report any security vulnerability promptly so that appropriate action can be taken.

To report a security issue in this SDK, please use [this repository's GitHub security advisories](https://github.com/cadenya/cadenya-go/security/advisories/new) to submit a private report.

## Responsible Disclosure

We appreciate the efforts of security researchers and individuals who help us maintain the security of
our SDKs. If you believe you have found a security vulnerability, please adhere to responsible
disclosure practices by allowing us a reasonable amount of time to investigate and address the issue
before making any information public.

## Reporting Non-SDK Related Security Issues

If you encounter security issues that are not directly related to this SDK but pertain to the services
or products provided by Cadenya, please contact support@cadenya.com.

---

Thank you for helping us keep our SDKs and the systems they interact with secure.
